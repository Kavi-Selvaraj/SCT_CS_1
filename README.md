# Task 1 – Caesar Cipher Encryption and Decryption

## Objective

To create a Python program that encrypts and decrypts text using the Caesar Cipher technique.

## Features

* Encrypts text using a user-defined shift value.
* Decrypts encrypted text.
* Supports uppercase and lowercase letters.
* Preserves spaces and special characters.

## Technologies Used

* Python

## How to Run

```bash
python main.py
```

## Example

**Input:**

```text
Message: Hello World
Shift: 3
```

**Encrypted Output:**

```text
Khoor Zruog
```

## Conclusion

The program successfully demonstrates basic text encryption and decryption using the Caesar Cipher technique.
